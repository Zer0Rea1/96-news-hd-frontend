# 96 News HD Admin

Private operating workspace for one owner. News, tags, reporters, and reporter activity share one navigation and session.

Dark canvas #101215, surfaces #191d23 and #16191f, borders #30353e, text #e8eaed, muted #a9afb9. Red only for brand and primary actions; green, amber, and muted red communicate statuses. Manrope for interface text, readable RTL article composition. No gradients, marketing copy, decorative metric cards, or motion unrelated to state changes. Compact status filters, table actions, plain headings, visible keyboard focus. Mobile navigation drawer and scrollable tables. Dialogs protect editing and destructive actions. Card artwork and QR export keep their original print colors.

All operations go through the shared API and its owner authorization. Printed profile links remain on profile.96newshd.com.
